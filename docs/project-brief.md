# Project brief

Goal: create a low-maintenance platform repo for building many simple AI-assisted brochure websites for local businesses.

Working assumptions from the source notes:
- hosting should stay cheap
- sites should be mostly static
- GitHub should be the source of truth
- Cloudflare Pages is the default hosting target
- handoff to a business owner later should be easy
- the workflow should support many parallel projects

Recommended operating model:
- build small static sites first
- avoid full backends unless clearly necessary
- use reusable templates and a per-client folder model
- charge for setup plus maintenance rather than raw hosting

Typical brochure-site sections:
- home
- services
- about
- gallery or photos
- contact
- map embed
- click-to-call
- email or contact form
